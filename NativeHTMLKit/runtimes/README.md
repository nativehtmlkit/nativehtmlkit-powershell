Core host binaries are NOT committed here. `scripts/package-local.py` copies a prebuilt Core host per runtime (`linux-x64/nativehtmlkit-host`, `win-x64/nativehtmlkit-host.exe`) after verifying its SHA-256, and records the hash in `HOST-MANIFEST.json`; the module refuses to run a bundled host that no longer matches. No Python or Rust is required to use the resulting PowerShell module. `NATIVEHTMLKIT_HOST_BINARY` overrides the host for local development.
